# Mixed defects: multi-label classification (MixedWM38)

[← Back to README](../../README.md) · [中文](../mixed-defects.md)

WM-811K gives each wafer one label, yet the confident errors (see [model diagnostics](model-diagnostics.md)) already include wafers with two overlapping patterns. MixedWM38 is a dataset made for mixed defects: 38,015 wafers of 52×52 dies, each with up to 4 patterns at once, in 38 combinations. The model is the same CNN, with the 9-way softmax output replaced by 8 independent sigmoids, each answering "is this pattern present?".

60/20/20 split stratified by combination, 3 random seeds, about 7,400 test wafers:

| Metric | Value |
|---|---|
| All 8 labels correct | 97.2% ± 0.3% |
| Mean F1 over the labels | 0.987 ± 0.002 |

More patterns are harder; the share with all labels correct drops with the number of patterns:

| Patterns on the wafer | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| All labels correct | 100% | 98.9% | 98.1% | 96.1% | 94.0% |

- The most common error is **missing Scratch**: 7 of the 8 worst combinations contain Scratch, and the error is always that the other patterns are right and only Scratch is missing. A long thin scratch is easily hidden when it overlaps another pattern. This matches Scratch being one of the weakest classes on WM-811K.
- The other weak spot is Near-full (F1 0.95), with only about 29 test wafers, mostly predicted as Random.

Two problems found in the data before using it:

- **1,024 wafers are exact duplicates**, 1,000 of them in a single combination, Center+Edge-Loc+Scratch (its 2,000 wafers contain only 1,000 distinct maps). Without deduplication the same map would land in both the training and the test set. Duplicates are removed before splitting, which leaves 36,991 wafers.
- 105 wafers contain the value 3, which the data description does not explain; it is treated as a failing die.

These scores are not comparable with the WM-811K scores: MixedWM38 has no lot information, so the split can only be random, and most mixed wafers were generated by a GAN, so their patterns are cleaner than real ones. The result shows that the method handles mixed defects and where the difficulty lies; it does not mean a real fab would see 97%.
